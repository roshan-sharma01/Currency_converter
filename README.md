# Currency_converter
💱 A responsive currency converter web app built with HTML, CSS, and JavaScript that helps users convert currencies from one country to another.

About the Project

💱 Currency Converter Web Application

A simple and user-friendly web application that allows users to convert currencies from one country to another. Users can enter an amount, select the source currency and target currency, and get the converted value.

The project is built using HTML, CSS, and JavaScript. JavaScript handles the conversion logic and user interactions, while HTML provides the structure and CSS creates a clean and responsive interface.

✨ Features
Convert one currency into another
Select currencies from different countries
Enter custom amounts for conversion
Simple and user-friendly interface
Responsive design
Real-time exchange rates
